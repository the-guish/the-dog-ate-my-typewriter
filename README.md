# the-dog-ate-my-typewriter

About things I wanted to share with you but I'm lazy or tired to write myself.  Ideation is mine, wording is 99% some combination of AI, some curation added to preserve relevance for your dry human eyes.  May the gods and history forgive us.

## Contents

- `_posts/`: published posts. `_drafts/`: unpublished ones.
- `notebooks/`: raw material behind the posts, in the repository only.
- The site is built by GitHub Pages with Jekyll, from `main`.

## Preview locally

```sh
bundle install
bundle exec jekyll serve --drafts
```
